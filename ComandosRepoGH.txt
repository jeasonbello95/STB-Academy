  ### 🚀 Pasos para Crear y Conectar Ambos Repositorios en GitHub

  #### 1. Iniciar sesión en GitHub CLI (solo se hace una vez)

  Abre cualquier terminal y ejecuta:

    gh auth login

  (Selecciona GitHub.com ➔ HTTPS ➔ Yes ➔ Login with a web browser e introduce el código que te aparezca).
  ──────
  #### 2. Crear los repositorios en GitHub

  • Para el Frontend:
  Ve a C:\Users\STB\Documents\Proyect1 y ejecuta:
    .\crear-repo.bat
  (o npm run crear-repo)
  • Para el Backend:
  Ve a C:\Users\STB\Local Sites\stbsite y ejecuta:
    .\crear-repo.bat


  (Ambos scripts crearán el repositorio en tu cuenta de GitHub y subirán la rama main automáticamente).
  ──────
  ### 🔄 Comandos del Día a Día para Ambos Proyectos

  #### ⬆️ Para SUBIR tus cambios hechos a GitHub

  (Agrega todos los archivos, hace commit con fecha o mensaje personalizado y sube a GitHub)

  • En el Frontend (Proyect1):
      • Vía NPM: npm run subir
      • Vía CMD / Terminal: .\subir.bat (o con mensaje: .\subir.bat "Nuevo componente")
      • Vía PowerShell: .\subir.ps1 (o .\subir.ps1 -Mensaje "Nuevo componente")
  • En el Backend (stbsite):
      • Vía CMD / Terminal: .\subir.bat (o con mensaje: .\subir.bat "Ajustes de plugins y tema")
      • Vía PowerShell: .\subir.ps1 (o .\subir.ps1 -Mensaje "Ajustes de plugins y tema")

  ──────

  • En el Frontend (Proyect1):
